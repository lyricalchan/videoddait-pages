# 개인정보 및 외부 연결 안내

최종 수정: 2026-09-19

VideoDdait는 리리컬이 제공하는 PC용 영상 처리 프로그램입니다. 이 안내는 프로그램 자체의 데이터 처리와 외부 구성요소·서비스의 동작을 구분해 설명합니다.

## PC에 저장하는 정보

영상 처리는 사용자의 PC에서 수행합니다. 프로그램은 영상·음원을 제작자 서버로 자동 업로드하지 않습니다.

프로젝트에는 선택한 파일 경로, 처리 설정과 작업 기록이 포함될 수 있으며, 프로그램 폴더의 Data에 저장됩니다. 약관 동의 기록에는 동의한 문서 묶음의 식별값만 저장합니다. 표시 언어와 테마 등 화면 설정은 로컬에 보관합니다. 임시 파일·캐시·WebView2 데이터도 처리 과정에서 PC에 생성될 수 있습니다.

위 Data 위치는 포터블판 기준입니다. Microsoft Store 설치판은 Windows가 관리하는 사용자별 앱 데이터 영역(LocalState)에 프로젝트·약관 동의 기록·모델·WebView2 데이터를 저장하며, 읽기 전용 설치 폴더에는 저장하지 않습니다. 포터블판의 기존 데이터를 자동으로 옮기거나 합치지 않습니다.

진단 JSON은 사용자가 저장을 선택한 경우에만 생성하며 자동 전송하지 않습니다. 진단 JSON에서 원본 영상·음원, 파일명·경로, 임의 로그와 사용자 모델명은 제외합니다. 프로젝트 파일이나 직접 보낸 로그까지 익명화한다는 의미는 아닙니다.

## 인터넷에 연결하는 경우

- **모델 다운로드:** 사용자가 다운로드를 시작하면 GitHub·Hugging Face 등의 제공처와 그 다운로드 서버에 연결합니다. 이 과정에서 IP 주소 등 통신에 필요한 정보가 해당 제공처에 전달될 수 있으며, 제공처의 개인정보처리방침이 적용됩니다. 입력 영상을 다운로드 요청에 첨부하지 않습니다.
- **외부 링크:** YouTube·Suno 등 링크를 열면 해당 사이트에 연결합니다. 각 서비스의 개인정보처리방침을 확인하세요.
- **Microsoft WebView2:** 화면 표시를 위해 포함된 WebView2에는 Microsoft의 약관이 적용됩니다. Microsoft Defender SmartScreen은 기본적으로 활성화되며, Microsoft가 안내하는 최종 사용자 정보를 수집하여 Microsoft로 전송합니다. 원본 영상을 Microsoft에 업로드한다는 의미는 아닙니다.

Microsoft 개인정보처리방침: https://aka.ms/privacy

SmartScreen 안내: https://learn.microsoft.com/en-us/microsoft-edge/privacy-whitepaper#smartscreen

이 문서는 확인된 프로그램 동작을 설명합니다. 모든 운영체제·드라이버·외부 구성요소의 네트워크 통신이 없다고 보장하지는 않습니다.

## 보관과 삭제

출력 영상은 문서/VideoDdait Output 또는 직접 지정한 폴더에 저장됩니다. OneDrive 등과 동기화되는 폴더를 선택한 경우에는 해당 동기화 서비스의 설정에 따라 파일이 전송될 수 있습니다.

프로그램을 종료한 뒤 필요 없는 프로젝트·모델·출력 파일을 직접 삭제할 수 있습니다. Data를 삭제하면 저장한 프로젝트와 약관 동의 기록도 사라지므로 먼저 필요한 내용을 백업하세요. 프로그램 폴더만 삭제해도 별도로 지정한 출력 폴더나 운영체제의 임시 데이터까지 모두 지워지는 것은 아닙니다.

Microsoft Store 설치판을 초기화하거나 제거하면 앱 전용 데이터와 다운로드 모델이 삭제될 수 있습니다. 필요한 프로젝트는 먼저 백업하세요. 문서 폴더 등 별도로 지정한 위치에 저장한 출력 영상은 앱 전용 데이터와 구분됩니다.
